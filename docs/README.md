# Documentation Guide

This directory has two kinds of documents:

1. **Current reference docs** used for day-to-day development.
2. **Session notes / historical records** kept for traceability.

## Current reference docs

Read these first:

1. [`current-status.md`](current-status.md) - latest project state and immediate next actions.
2. [`requirements.md`](requirements.md) - current requirements and milestones.
3. [`architecture.md`](architecture.md) - current ROS 2 architecture and package responsibilities.
4. [`implementation-plan.md`](implementation-plan.md) - phased plan and checklist.
5. [`development-workflow.md`](development-workflow.md) - laptop-to-robot workflow.
6. [`electrical-wiring-and-power-plan.md`](electrical-wiring-and-power-plan.md) - wiring and power safety.
7. [`open-questions.md`](open-questions.md) - unresolved decisions.
